# 🂡 Система торговли — Бридж

Система торговли 2/1 Game Force в формате LaTeX с автоматической сборкой PDF.

## Структура

```
main.tex                    ← главный файл (не трогать обычно)
sections/
  macros.tex                ← макросы (масти, биды, маркеры)
  openings.tex              ← открытия и ответы
  competitive.tex           ← конкурентная торговля
  defensive.tex             ← защитная торговля
  signals.tex               ← сигналы и ходы
  conventions.tex           ← специальные конвенции
.github/workflows/build.yml ← автосборка PDF
```

## Как редактировать

### С Claude Code (рекомендуется)
```bash
claude
> добавь конвенцию Лебенсол в раздел защитной торговли
> измени диапазон открытия 1NT на 14-16
> добавь раздел про ребиды открывшего после 1♥
```

### Вручную
Редактируйте файлы в `sections/`. Основные макросы:

| Макрос | Результат |
|--------|-----------|
| `\s \h \di \cl \nt` | ♠ ♥ ♦ ♣ NT (цветные) |
| `\bid{1}{\h}` | **1♥** |
| `\gf \fone \inv \so \al` | Маркеры: GF, F1, INV, SO, AL |
| `\bidrow{бид}{сила}{описание}` | Строка таблицы |

Для добавления новой секции:
```latex
\bidsectionstart{Название}
  \bidrow{\bid{1}{\s}}{12--21}{Описание бида}
  \bidrow{\bid{2}{\cl}}{11+}{Другой бид\gf}
\bidsectionend
```

## Сборка

### Локально
```bash
xelatex main.tex && xelatex main.tex
```

### Автоматически
При каждом `git push` в `main` GitHub Actions собирает PDF и создаёт релиз.
Свежий PDF всегда доступен во вкладке **Releases**.

## Шаринг с партнёром

1. Добавьте партнёра как collaborator в репозитории
2. Партнёр клонирует репо и редактирует (тоже может через Claude Code)
3. Оба пушите изменения → PDF автоматически пересобирается
4. Свежий PDF скачивается из Releases
